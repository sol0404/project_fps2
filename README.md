# 블록 아레나

블록형 3D FPS (웹 + 멀티). 개인전, 방 코드로 입장, 한 방 최대 5명. PC·모바일 크로스 플레이.

이 게임만의 규칙:

- **망령 시스템**: 라운드 중에 죽으면 망령이 되어 벽을 통과해 날아다니며, 8초마다 블록을 놓거나 지울 수 있다. 내 블록이 총알을 막으면 코인을 받고, 다음 자기장 위치에 투표할 수 있다.
- **라운드 규칙 카드**: 라운드에서 가장 먼저 죽은 사람이 다음 라운드 규칙을 3장 중 하나로 고른다 (저중력, 헤드샷만, 블록 탄, 안개, 거인, 거꾸로 자기장).
- **캐릭터** (project_fps에서 합침): 치이카와(체력 120·회복), 하치와레(100·대시), 우사기(90·높이 뛰기). 캐릭터마다 고유 무기가 기본 권총 자리를 대신하고, 상점 무기는 똑같이 산다.
- 그 밖에: 라운드제(구매 15초 → 전투, 먼저 5승), 무기 5종 상점, 줄어드는 자기장, 부서지는 블록, 서버 판정(되감기 명중 판정)

## 실행

```
npm install
npm start          # http://localhost:3000
```

같은 와이파이의 친구는 `http://<내 IP>:3000`, Tailscale이면 Tailscale IP로 접속.

## 테스트

`DEV=1 npm start`로 띄우면 테스트용 순간이동(`{t:'tp'}`) 메시지를 받는다. 평소엔 꺼 둔다.

## 구조

- `shared/map.js` 블록 맵 (서버·클라이언트가 같은 함수로 생성)
- `shared/sim.js` 이동·무기 (서버 판정 + 클라이언트 예측이 같은 코드 사용)
- `shared/ray.js` 사격 광선 검사 (블록, 머리·몸통 판정 상자)
- `shared/zone.js` 자기장 일정
- `shared/characters.js` 캐릭터 (체력·속도·고유 무기·스킬). 스킬 이동은 `sim.js`의 `stepPlayer`가 처리해 서버 판정과 예측이 같다
- `client/assets.js` 캐릭터 GLB 불러오기·썸네일, `client/models/` 캐릭터 모델 (CC BY-NC 4.0)
- `server/index.js` 정적 파일 + WebSocket, 60틱 판정, 초당 20번 상태 전송
- `client/world.js` 장면·맵·아바타, `client/fx.js` 총 모델·탄 궤적·소리, `client/minimap.js` 미니맵, `client/touch.js` 터치 조작, `client/main.js` 네트워크·입력·HUD·상점
